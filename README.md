# 🐶 Buddy Pet：和搭子互相监督的桌面小狗

桌面右下角会有一只小狗，它代表你的搭子：

- **实时状态**：小狗的样子跟着对方变。学习时抱着电脑点头，摸鱼时歪着玩手机，离开电脑就睡觉（Zzz），离线时变灰。
- **悬停查看**：鼠标放上去会显示对方正在用的应用或网站（比如「正在看 哔哩哔哩」），以及 TA 已经连续摸鱼多久；下面并排列出你和搭子各自的今日学习、摸鱼时长（搭子不在线时只显示你自己的）。
- **戳一下**：点击小狗，可以选预设的话或者自己打一句发过去。对方桌面会弹出系统通知，对方的小狗也会抖一下并冒出气泡。每 30 秒只能戳一次，防止刷屏。
- **自我提醒**：你自己连续摸鱼达到 20、40、60 分钟时，小狗会先提醒你“TA 能看到哦”。
- **早上计划、晚上复盘**：早上弹窗写今日计划，白天随时勾选，晚上逐条复盘（没完成的要写原因）。对方能看到你的进度和复盘，详见下面第 5 节。
- **隐私**：只分享**应用名和域名**，不发完整网址和窗口标题。可以设置隐私网站和隐私应用，对方只会看到「隐私模式」。托盘菜单里可以一键「暂停分享」。

```
buddy-pet/
├── server/      中转服务器（Node + WebSocket，约 150 行）
├── client/      Windows 桌面客户端（Electron）
├── extension/   Chrome / Edge 插件（把当前标签页的域名告诉本机小狗）
└── tests/       测试（在 client/ 下运行 npm test）
```

---

## 1. 部署服务器（只需一个人做一次）

服务器只负责转发消息，两个人连同一个地址即可。

**本地试跑：**
```bash
cd server
npm install
npm start          # 默认端口 8787，可用 PORT 环境变量修改
```

**正式部署**：任何能跑 Node 的平台都可以，比如 Railway、Render、Fly.io 或自己的云服务器。把 `server/` 目录部署上去，启动命令填 `npm start`。平台会给一个域名，客户端里填 `wss://你的域名` 即可。

> 注意：免费套餐的服务可能在没有访问时休眠，导致断线。客户端会自动重连，但如果经常断，换一个不休眠的方案会更稳。

## 2. 安装桌面客户端（两个人都要装）

需要 Node.js 18 或更高版本。

```bash
cd client
npm install
npm start          # 直接运行
npm test           # 跑测试
npm run dist       # 打包成安装包和便携版 exe，输出在 client/dist/
```

打包好后，把 `dist/` 里的安装包发给朋友，对方就不用装 Node 了。

- 打包要在 Windows 上运行，不需要管理员权限。下载 Electron 太慢的话，先设置环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再安装。
- `Buddy Pet Setup x.y.z.exe` 是安装版，`Buddy Pet x.y.z.exe` 是便携版（双击直接运行）。便携版第一次启动时会在开始菜单里放一个「Buddy Pet」快捷方式：Windows 靠它来识别系统通知是谁发的，没有的话通知不显示应用名和图标。不用便携版了可以直接删掉这个快捷方式。

第一次打开会弹出设置页，填写以下几项：

| 项 | 说明 |
|---|---|
| 服务器地址 | `wss://...`，本地测试填 `ws://localhost:8787` |
| 房间号 / 房间密码 | **两个人填一样的**。第一个连上的人会创建这个房间 |
| 我的昵称 | 两个人**不一样**，会显示在对方小狗的名牌上 |

小狗的名牌可以**拖动**来移动位置。右下角托盘图标里有：暂停分享、显示或隐藏小狗、今日计划、明日计划、今日复盘、设置、退出。

## 3. 安装浏览器插件（推荐）

不装插件也能用：客户端会根据窗口标题判断，比如标题里有「哔哩哔哩」就算摸鱼。装上插件后能拿到准确的域名。

1. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`）
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选择 `extension/` 文件夹
4. 点插件图标，显示「✓ 已连接到桌面小狗」就成功了

插件只把**域名**发到本机的 `127.0.0.1:17321`，不会发到外网。安装时 Chrome 会提示“读取浏览记录”，这是因为读取标签页网址需要 `tabs` 权限。

## 4. 判定规则

在「设置 → 判定规则」里可以自己编辑：

- 📚 **学习网站和应用**：默认包括 Claude、ChatGPT、GitHub、LeetCode、Overleaf、各种 `.edu` 网站，以及 VS Code、Word、PyCharm、终端等
- 🐟 **摸鱼网站和应用**：默认包括 B 站、抖音、小红书、微博、知乎、YouTube、淘宝，以及 Steam、原神等
- 其他都算「在电脑前」（中性），比如微信
- 键鼠空闲超过 5 分钟（可调）算「离开」。**例外**：在摸鱼网站上不动鼠标（比如看视频）要 20 分钟才算离开，所以别想靠看视频不动鼠标来蒙混 😏

应用要填**进程名**，可以在任务管理器 →「详细信息」里看到，去掉 `.exe` 即可，比如 `Code`、`WINWORD`、`steam`。

## 5. 早上计划和晚上复盘

- **早上**：到了计划提醒时间（默认 09:00），或者当天第一次用电脑时（5 点以后），会弹出「今日计划」，写 1–8 件要做的事。现在没空可以点「15 分钟后再提醒」，最多推迟 3 次。
- **白天**：托盘菜单 →「今日计划」，做完一件勾一件，也可以增删条目。改动自动保存。
- **晚上**：到了复盘提醒时间（默认 22:00）弹出「今日复盘」，逐条标记完成或没完成。**没完成的必须写原因**才能提交，还可以写一句「明天想改进的地方」。昨晚忘了复盘的话，第二天写新计划之前，托盘菜单里的「今日复盘」打开的是昨天的，可以补交。
- **对方能看到什么**：
  - 小狗悬停卡片上的进度，比如「计划 2/4」；还没写就显示「还没写今日计划」
  - 你提交计划或复盘时，对方的小狗会冒气泡：「Tom 写好了今日计划」
  - 点小狗 →「查看 TA 的今日计划/复盘」，可以看到每一条的内容、没完成的原因和改进点（只读）
- **提前写明天的**：托盘菜单 →「明日计划」（设置页历史的第一行也能进）。写好后到了明天它就是今日计划，早上不会再弹窗。明天的计划先只存在自己电脑上，对方到那天才看得到。
- **历史**：「设置 → 明天和最近 7 天」列出每天两个人的完成率，点开能看当天的计划和复盘。日期过了零点会自动更新。
- 两个提醒时间在「设置 → 计划和复盘」里改，复盘时间要晚于计划时间。

数据存在哪：

- 计划和复盘存在**自己电脑**上的 `%APPDATA%/Buddy Pet/journal/YYYY-MM-DD.json`，每天一个文件，里面同时有你自己的和收到的对方那份。
- 服务器**不存盘**，只在内存里缓存每人最新的一份，方便后上线的人立刻看到。服务器重启后缓存会清空，客户端每次连上都会自动重发自己当天的内容。
- **暂停分享**期间，计划的任何变化都不会发给对方；恢复分享后会补发最新的一份。计划和复盘里只有你自己手写的内容，不包含窗口标题、应用名或网址。

## 工作原理

```
┌──────────── 你的电脑 ────────────┐                ┌──── 搭子的电脑 ────┐
│ PowerShell 每 2 秒读前台窗口      │                │                    │
│ + 浏览器插件发来的域名            │   WebSocket    │                    │
│        ↓ 分类 / 计时              │ ─────────────→ │  小狗变成对应状态   │
│   Electron 主进程 ── status ──────┼──→ 中转服务器 ─┼──→                 │
│   小狗窗口 ←──────── poke ────────┼─── (房间+密码)←┼── 点击小狗戳你     │
│   今日计划 / 复盘 ←── journal ────┼──→  (内存缓存) ←┼──→ 对方的计划/复盘  │
└──────────────────────────────────┘                └────────────────────┘
```

- `client/win-activity.ps1`：通过 Win32 API（GetForegroundWindow、GetLastInputInfo）获取前台进程、窗口标题和空闲时长。不需要编译原生模块。进程名和标题都用 base64 输出，中文不会乱码。
- `client/classifier.js`：分类规则，是纯函数。
- `client/activity.js`：累计今日时长（跨天自动清零，存在 `%APPDATA%/Buddy Pet/today.json`）和连续摸鱼时长。
- `client/journal.js`：计划和复盘的字段清洗、本机存储、提醒时机（什么时候该弹窗）、和对方同步。不依赖 Electron；窗口在 `client/renderer/journal.html`。
- `server/server.js`：房间、密码校验、状态和 journal 缓存（后加入的人能立刻看到对方的状态和今日计划）、戳一戳限流、心跳检测。journal 和 poke 一样会做字段清洗和长度限制，单条消息上限 8KB。
