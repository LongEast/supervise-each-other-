# 🐶 Buddy Pet：和搭子互相监督的桌面小狗

桌面右下角会有一只小狗，它代表你的搭子：

- **实时状态**：小狗的样子跟着对方变。学习时抱着电脑点头，摸鱼时歪着玩手机，离开电脑就睡觉（Zzz），离线时变灰。
- **悬停查看**：鼠标放上去会显示对方正在用的应用或网站（比如「正在看 哔哩哔哩」），以及 TA 已经连续摸鱼多久；下面并排列出你和搭子各自的今日学习、摸鱼时长（搭子不在线时只显示你自己的）。
- **时长明细**：点卡片上的某个时长，可以看到这段学习或摸鱼时间花在了哪些网站和应用上（比如「VS Code 45m、Claude 20m」）。自己的和搭子的都能看；鼠标移开就收起。卡片上只列时间最长的 6 项，点最后一行的「其他 · 看全部」会打开面板的「统计」页，里面是完整的列表。
- **面板和统计**：右键小狗 →「今日计划」「统计」「设置」直接到对应的那一页，或者「打开面板」（托盘菜单里也有），一个窗口四页：
  - **今天**：番茄钟（在这里开始、休息、结束）、你和搭子现在的状态和今天的时长、两个人的今日计划。
  - **统计**：按天或按周看自己的数据——学习和摸鱼时长、计划完成了几条、专注完了几个番茄；按天能看每个小时学了多久、时间花在哪些应用和网站上，按周是每天一根柱子，外加这一周最常用的。左右箭头翻到以前的日子。搭子的也能看（时长是 TA 在线时发过来的那部分，没有按小时的分布和番茄数）。
  - **计划**：写今天和明天的计划、复盘、看历史，见下面第 5 节。
  - **设置**：连接、判定规则、各种提醒，还有小狗的大小、显示谁、换形象、检查更新。
  - 按天的时长是从有面板的这一版开始存的（`%APPDATA%/Buddy Pet/history/` 下每天一个文件），之前的日子只有计划和复盘，没有时长。
- **看自己**：右键小狗（或名牌），选「显示我自己的状态」，小狗就改成演你自己：学习、摸鱼、离开时的样子和搭子那边看到的你一样，名牌变成棕色的「我 · 学习中」，卡片上是你正在用的应用或网站、连续摸鱼多久、今日计划进度。这时点小狗打开的是自己的今日计划。再右键选「显示搭子的状态」换回来；选择会记住。
- **换形象**：不想要小狗的话，右键小狗（或「面板 → 设置」）→「换个形象」→「🐱 小猫」，换成一只灰白色的小猫：学习时一样抱着电脑，平时半眯着眼，摸鱼时张嘴举着手机，鼠标放上去或者蹦一下的时候会举起两只爪子。只改你自己桌面上这只的样子，演的还是同一个人，搭子那边不受影响；选择会记住。换了以后菜单、气泡里的称呼和托盘图标也跟着变成小猫；下面说的「小狗」换成小猫以后也都一样。
- **戳一下**：点击小狗，可以选预设的话或者自己打一句发过去。对方桌面会弹出系统通知，对方的小狗也会抖一下并冒出气泡。每 30 秒只能戳一次，防止刷屏。
- **该学习啦**：你自己每连续摸鱼 5 分钟，会弹出一个置顶的小窗口提醒你（要自己点掉），小狗也会抖一下冒气泡。窗口里有个下拉框「再过多久提醒我」，可以临时把下一次改成 10、20 或 40 分钟后，再下一次又回到 5 分钟；回去学习后窗口自己关掉，计时重新开始。只提醒你自己，不会通知搭子。默认间隔和下拉框里可以选的时间都能在「设置 → 摸鱼提醒」里改，也可以整个关掉。
- **番茄钟**：右键小狗（或托盘菜单）→「开始番茄钟」，默认专注 25 分钟、休息 5 分钟，轮着来，直到右键选「结束番茄钟」。每次休息结束都要你点一下「重新开始番茄钟」，下一轮才开始计时。小狗左上角有倒计时（红色是专注，绿色是休息），右键菜单里还能「现在就休息」或「跳过休息」。
  - **到休息时间**只冒气泡，不弹窗。**休息结束**时会弹出置顶的「休息结束啦」窗口，番茄钟停在那里等你选：点「重新开始番茄钟」，新一轮专注从这一刻开始计时；点按钮下面的小箭头，可以换成「再休息一会」（按设置里的休息时长再休息一段，结束后还会再问）；点「恢复默认模式」就结束番茄钟，回到平时的样子。直接把窗口关掉的话番茄钟还停着（小狗左上角显示「等你开始」），右键小狗或托盘菜单里也能选这三项。等着的这段时间不算休息，摸鱼照常算摸鱼。
  - 休息是说好的：休息时摸鱼**不算摸鱼时间**，「连续摸鱼」从零开始，也不会弹摸鱼提醒。休息时间默认也**不算学习时间**（休息时还在接着学的照常算）；在「设置 → 番茄钟」里勾上「休息时间也计入学习时间」，整段休息就都算学习（离开电脑也算），明细里记在「🍅 番茄钟休息」下面。
  - 专注和休息的时长在「设置 → 番茄钟」里改，从下一段开始生效。搭子的卡片上能看到你「番茄钟专注中 / 休息中 · 还剩几分钟」，休息结束还没开始下一轮时也看得到。一整轮（专注 + 休息）都没碰电脑，或者电脑睡了一觉，番茄钟会自己停掉（「休息结束啦」一直没人点也一样）；退出小狗后也不会接着跑。
  - **严格模式**（「设置 → 番茄钟」里勾上，默认关）：专注时一摸鱼，倒计时就停住（小狗左上角变成灰色的 🐟），回去学习才接着走——摸鱼的时间不算进番茄钟。想歇一下可以「暂停 5 分钟」（面板「今天」页的「暂停」，或者右键小狗）；到点会弹出置顶的「暂停时间到啦」窗口，倒计时不会自己接着走，等你选：「继续专注」从暂停时剩下的时间接着走，「5 分钟后再提醒」接着暂停，「退出番茄钟」就结束。暂停中也可以提前点「继续专注」。暂停的这段时间摸鱼照常算摸鱼，只是不另外弹摸鱼提醒。搭子的卡片上能看到你的番茄钟停着或者暂停中。
- **早上计划、晚上复盘**：早上弹窗写今日计划，白天随时勾选，晚上逐条复盘（没完成的要写原因）。对方能看到你的进度和复盘，详见下面第 5 节。
- **隐私**：只分享**应用名和域名**，不发完整网址和窗口标题；时长明细也一样，只精确到网站和应用，看不到具体网页，每类最多发时间最长的 30 项（自己看自己的没有这个限制）。可以设置隐私网站和隐私应用，对方只会看到「隐私模式」，这些也不会出现在明细里。托盘菜单里可以一键「暂停分享」，暂停期间的活动不计时、不进明细。

```
buddy-pet/
├── server/      中转服务器（Node + WebSocket，约 150 行）
├── client/      Windows 桌面客户端（Electron）
├── extension/   Chrome / Edge 插件（把当前标签页的域名告诉本机小狗）
└── tests/       测试（在 client/ 下运行 npm test）
```

## 1. 部署服务器（只需一个人做一次）

服务器只负责转发消息，两个人连同一个地址即可。

**本地试跑：**
```bash
cd server
npm install
npm start          # 默认端口 8787，可用 PORT 环境变量修改
```

**正式部署**：任何能跑 Node 的平台都可以，比如 Railway、Render、Fly.io 或自己的云服务器。把 `server/` 目录部署上去，启动命令填 `npm start`。平台会给一个域名，客户端里填 `wss://你的域名` 即可。

> 注意：免费套餐的服务可能在没有访问时休眠，导致断线。客户端会自动重连，但如果经常断，换一个不休眠的方案会更稳。

## 2. 安装桌面客户端（两个人都要装）

需要 Node.js 18 或更高版本。

```bash
cd client
npm install
npm start          # 直接运行
npm test           # 跑测试
npm run dist       # 打包成安装包和便携版 exe，输出在 client/dist/
```

打包好后，把 `dist/` 里的安装包发给朋友，对方就不用装 Node 了。

- 打包要在 Windows 上运行，不需要管理员权限。下载 Electron 太慢的话，先设置环境变量 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再安装。
- `Buddy-Pet-Setup-x.y.z.exe` 是安装版，`Buddy-Pet-x.y.z-portable.exe` 是便携版（双击直接运行）。便携版第一次启动时会在开始菜单里放一个「Buddy Pet」快捷方式：Windows 靠它来识别系统通知是谁发的，没有的话通知不显示应用名和图标。不用便携版了可以直接删掉这个快捷方式。

**自动更新**：安装版启动后（之后每 6 小时）会到 GitHub Release 查有没有新版本，有就在后台下载，下好了弹窗问要不要现在重启更新；选「稍后」的话下次退出时自动装上。设置和计划记录都会保留。便携版没法替换自己，只会提示有新版本并打开下载页。托盘菜单或「面板 → 设置」最下面的「检查更新」可以手动查；新版本下载好以后，这一项会变成「重启并更新」。

发新版本的步骤（不用在自己电脑上打包，GitHub Actions 会做）：

1. 改 `client/package.json` 里的 `version`（更新靠版本号比较，必须比上一版大），在 `CHANGELOG.md` 最上面加一节 `## x.y.z` 写这一版改了什么，提交并推送。
2. 推一个同名的 tag：`git tag vx.y.z && git push origin vx.y.z`。
3. `.github/workflows/release.yml` 会先跑测试，再在 Windows 上打包，然后建好 Release，把安装版、便携版、`latest.yml`、`.blockmap` 四个文件和浏览器插件的 ZIP 传上去，大约十分钟。之后已经装好的安装版就会收到更新。tag 和 `version` 对不上，或者测试没过，就不会发。

想先试用再发：在 GitHub 的 Actions 页面手动运行「打包发布」，它只打包不发 Release，安装包在那次运行的 Artifacts 里。自己手动发也行：`npm run dist` 之后把上面四个文件原名传到 tag 为 `vx.y.z` 的 Release。少了 `latest.yml`，已经装好的客户端就查不到这一版；`.blockmap` 让更新只下载变化的部分。

第一次打开会弹出设置页，填写以下几项：

| 项 | 说明 |
|---|---|
| 服务器地址 | `wss://...`，本地测试填 `ws://localhost:8787` |
| 房间号 / 房间密码 | **两个人填一样的**。第一个连上的人会创建这个房间 |
| 我的昵称 | 两个人**不一样**，会显示在对方小狗的名牌上 |

**移动**：按住小狗（或它下面的名牌）拖动。**调大小**：鼠标放在小狗身上滚滚轮，往上滚放大、往下滚缩小（60%–250%），「面板 → 设置」里也有几档可选。位置和大小都会记住。**关掉小狗**：右键小狗 →「退出 Buddy Pet」（或「隐藏小狗」，只是先藏起来）；任务栏图标上的「关闭窗口」只会关掉设置、计划这些窗口，小狗还在。右下角托盘图标（Windows 11 上可能收在「^」里）的菜单里是不常用的和小狗藏起来时也得能点的：打开面板、番茄钟、暂停分享、显示或隐藏小狗、检查更新、退出。常用的都在右键小狗的菜单里：显示谁、换形象、番茄钟、今日计划、统计、设置、暂停分享、隐藏和退出；小狗大小在「面板 → 设置」里（或者直接在它身上滚滚轮）。

## 3. 安装浏览器插件（推荐）

不装插件也能用：客户端会根据窗口标题判断，比如标题里有「哔哩哔哩」就算摸鱼。装上插件后能拿到准确的域名。

插件没有上架应用商店，要用「开发者模式」从文件夹加载：

1. **下载**：点 [Buddy-Pet-Extension.zip](https://github.com/LongEast/supervise-each-other-/releases/latest/download/Buddy-Pet-Extension.zip)（也在 [Release 页面](https://github.com/LongEast/supervise-each-other-/releases/latest)的文件列表里）。
2. **解压**：右键这个 ZIP →「全部解压缩」，得到一个 `Buddy-Pet-Extension` 文件夹，里面直接能看到 `manifest.json`。把文件夹放到一个不会删的地方（比如「文档」）：Chrome 是直接从这个文件夹读插件的，**删掉或挪走，插件就失效了**。Chrome 不能直接装 ZIP，必须先解压。
3. Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），打开右上角的「开发者模式」（Edge 的开关在左下角）。
4. 点左上角的「加载未打包的扩展程序」（有的版本写的是「加载已解压的扩展程序」，Edge 上是「加载解压缩的扩展」），选刚才解压出来的那个文件夹（要选里面有 `manifest.json` 的那一层）。
5. 点浏览器工具栏上的拼图图标 → Buddy Pet 网站助手，显示「✓ 已连接到桌面小狗」就成功了。小狗的设置页最上面也会显示「浏览器插件：已连接」。

Chrome 和 Edge 都用的话，两边各装一次，用同一个文件夹就行。有时浏览器启动会提示「请停用以开发者模式运行的扩展程序」，点关闭或保留即可，不要点停用。

**更新插件**：下载新的 ZIP，解压后覆盖原来的文件夹，再到扩展页面点这个插件卡片上的刷新按钮。插件很少改动，小狗更新后一般不用动它。

手里有源码的话不用下载 ZIP，第 4 步直接选仓库里的 `extension/` 文件夹。

插件只把**域名**发到本机的 `127.0.0.1:17321`，不会发到外网。安装时 Chrome 会提示“读取浏览记录”，这是因为读取标签页网址需要 `tabs` 权限。

## 4. 判定规则

在「设置 → 判定规则」里可以自己编辑：

- 📚 **学习网站和应用**：默认包括 Claude、ChatGPT、GitHub、LeetCode、Overleaf、各种 `.edu` 网站，以及 VS Code、Word、PyCharm、终端等
- 🐟 **摸鱼网站和应用**：默认包括 B 站、抖音、小红书、微博、知乎、YouTube、淘宝，以及 Steam、原神等
- **两个名单都不在的网站和应用也算学习时间**，比如微信、文件管理器、名单外的网站：小狗显示「学习中」，时间计入学习，明细里能看到具体是哪些。所以真正起作用的是摸鱼名单——发现哪个摸鱼网站被算成了学习，把它加进摸鱼名单就行。和学习名单里的区别只有一点：名单外的不会清零「连续摸鱼」计时，切出去回个消息再回来，连续摸鱼时长接着算
- 隐私名单里的不算学习也不算摸鱼
- 键鼠空闲超过 5 分钟算「离开」。**例外**：在摸鱼网站和应用上不动鼠标（比如看视频）要 20 分钟才算离开，所以别想靠看视频不动鼠标来蒙混 😏 两个时间都能在这一栏最下面改，摸鱼时的不能比平时的短

应用要填**进程名**，可以在任务管理器 →「详细信息」里看到，去掉 `.exe` 即可，比如 `Code`、`WINWORD`、`steam`。

## 5. 早上计划和晚上复盘

- **早上**：到了计划提醒时间（默认 09:00），或者当天第一次用电脑时（5 点以后），会弹出「今日计划」，写 1–8 件要做的事。现在没空可以点「15 分钟后再提醒」，最多推迟 3 次。
- **白天**：面板的「今天」页或「计划」页里，做完一件勾一件；「计划」页里还可以增删条目。改动自动保存。
- **晚上**：到了复盘提醒时间（默认 22:00）弹出「今日复盘」，逐条标记完成或没完成。**没完成的必须写原因**才能提交，还可以写一句「明天想改进的地方」。不想等弹窗的话，「面板 → 计划」最下面随时可以复盘。昨晚忘了复盘的话，第二天在「计划」页右下角「最近 7 天」里，昨天那一行有「补复盘」。
- **对方能看到什么**：
  - 小狗悬停卡片上的进度，比如「计划 2/4」；还没写就显示「还没写今日计划」
  - 你提交计划或复盘时，对方的小狗会冒气泡：「Tom 写好了今日计划」
  - 点小狗 →「查看 TA 的今日计划/复盘」，可以看到每一条的内容、没完成的原因和改进点（只读）
- **提前写明天的**：「面板 → 计划 → 明天」（「今天」页上的「明日计划」按钮也能进）。写好后到了明天它就是今日计划，早上不会再弹窗。明天的计划先只存在自己电脑上，对方到那天才看得到。
- **历史**：「面板 → 计划 → 历史」列出明天和最近 7 天每天两个人的完成率，点开能看当天的计划和复盘。日期过了零点会自动更新。
- 两个提醒时间在「设置 → 计划和复盘」里改，复盘时间要晚于计划时间。

数据存在哪：

- 计划和复盘存在**自己电脑**上的 `%APPDATA%/Buddy Pet/journal/YYYY-MM-DD.json`，每天一个文件，里面同时有你自己的和收到的对方那份。
- 服务器**不存盘**，只在内存里缓存每人最新的一份，方便后上线的人立刻看到。服务器重启后缓存会清空，客户端每次连上都会自动重发自己当天的内容。
- **暂停分享**期间，计划的任何变化都不会发给对方；恢复分享后会补发最新的一份。计划和复盘里只有你自己手写的内容，不包含窗口标题、应用名或网址。

## 工作原理

```
┌──────────── 你的电脑 ────────────┐                ┌──── 搭子的电脑 ────┐
│ PowerShell 每 2 秒读前台窗口      │                │                    │
```

- `client/win-activity.ps1`：通过 Win32 API（GetForegroundWindow、GetLastInputInfo）获取前台进程、窗口标题和空闲时长。不需要编译原生模块。进程名和标题都用 base64 输出，中文不会乱码。
- `client/classifier.js`：分类规则，是纯函数。
- `client/activity.js`：累计今日时长（存在 `%APPDATA%/Buddy Pet/today.json`，跨天时归档再清零）和连续摸鱼时长；今天的番茄数、按小时的分布、搭子今天的时长也记在这一份里。
- `client/history.js`：按天的记录（`history/YYYY-MM-DD.json`）怎么存、怎么清洗，以及「统计」页要的按天 / 按周汇总。不依赖 Electron。
- `client/renderer/panel.html` / `panel.js` / `panel.css`：面板。设置页的表单逻辑还在 `settings.js`，由面板加载。
- `client/pomodoro.js`：番茄钟的计时规则（什么时候换到下一段、休息结束后等着点「重新开始」、人不在时自己停；严格模式下摸鱼时停住、暂停 5 分钟），纯逻辑。休息时间怎么计时在 `activity.js` 的 `setRest()`。
- `client/journal.js`：计划和复盘的字段清洗、本机存储、提醒时机（什么时候该弹窗）、和对方同步。不依赖 Electron；窗口在 `client/renderer/journal.html`。
- `server/server.js`：房间、密码校验、状态和 journal 缓存（后加入的人能立刻看到对方的状态和今日计划）、戳一戳限流、心跳检测。journal 和 poke 一样会做字段清洗和长度限制，单条消息上限 8KB。
